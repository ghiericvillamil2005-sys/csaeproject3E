HTTP Inspection Trace

Note: example.com is reserved for documentation examples. The Week 4 exercise uses it to inspect a sample HTTP response; do not treat it as a production service or use it for ongoing testing or monitoring. Record the values you observe in your browser's Network tab because response details can vary.

1. https://example.com
Request Method: GET
Status Code: 200 OK
Content-Type: text/html; charset=utf-8

2. https://jsonplaceholder.typicode.com/posts/9999
Status Code: 404 Not Found
Meaning: The requested post does not exist.
Response Content-Type: application/json; charset=utf-8

3. https://example.com/nothing-here
Status Code: 404 Not Found
Meaning: The requested page or resource was not found.

Why a browser makes several requests:
A browser can make one request for the HTML document and additional requests for linked resources such as CSS, JavaScript, images, fonts, and API data needed to display and operate the page.
